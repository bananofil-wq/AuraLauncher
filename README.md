# Aura Launcher

Minimalistisk premium-launcher för Android, primärt designad för Pixel 8 Pro.

## v0.1
- Registreras som Android HOME-app
- Minimalistisk Aura-hemskärm
- Installerade appar i egen applåda
- Edge-to-edge mörk premiumgrund
- GitHub Actions bygger APK automatiskt

Nästa steg: riktiga appikoner, gestures, widgets, fokuslägen, wallpaper, sök, mappar och layout-editor.
